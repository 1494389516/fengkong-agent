# DBOS investigation recovery experiment (archived)

The recovery probe and its experimental requirements were removed on 2026-10-09
along with the repository test suite. The code is available in Git history at
commit `6ac8b7a1fb762235924958973f81da36aba40416`.

The completed experiment checkpointed synthetic evidence and a plan generated by
the Agent plan module, then killed and restarted the report worker. It observed
one evidence execution, one plan execution and two report attempts. No LLM was
called and no production action was authorized.

Adoption decision: keep DBOS experimental. These historical results establish
completed-step replay after a process crash, not multi-host failover, application
upgrades, provider exactly-once execution or throughput. Production adoption still
requires authenticated worker admission, budget/run-ledger integration, ambiguous
call handling, version-compatible recovery and a recovery coordinator. DBOS is
not a production dependency.
